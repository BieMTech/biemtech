Settings

Tweak every aspect of the app — sounds, language, Speed Mode timer, visual theme, and more. All changes take effect immediately.

🔊 Audio & Haptics

🔊

Sound Effects

Toggle all in-game sound effects on or off — correct answer chimes, wrong answer buzzes, and UI clicks.

📳

Vibration

Toggle haptic feedback on or off. When enabled, a short vibration plays on answer feedback events.

⚡ Speed Mode Duration

Set the default countdown timer for Speed Mode. This setting persists — every future Speed Mode run uses this duration until you change it again:

20 s 30 s 40 s 60 s
💡 30 seconds is the default. Younger children may prefer 60 s for a more relaxed experience; older children can challenge themselves with 20 s.

🎨 Theme & Appearance

Tap Change Theme to return to the Theme Selection screen. Your current theme is shown next to the button so you always know which one is active.

Available themes: 🌿 Forest · ✏️ Colorful · 🍬 Kawaii · 🚀 Cosmic

📊 Daily Limit Info

The current daily question limit is displayed here as a read-only reference. To change the limit, parents must use the Parent Dashboard (PIN protected).
